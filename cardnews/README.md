# 카드뉴스 자동 생성 파이프라인 — 「이주의 축제모아」

Vol.1(2026-08-21)에서 만든 6장 카드뉴스 템플릿을 매주 재사용할 수 있게 토큰화한 것.

## 파일
- `template.html` — 1080×1350 카드 6장(`#c1`~`#c6`), `{{TOKEN}}` 자리에 이번 회 텍스트를 채워 넣는다.
- `render.py` — `template.html`을 채워 Playwright로 카드마다 PNG를 뽑는다. **클라우드 샌드박스**(Playwright
  사전 설치돼 있음)에서 실행할 것 — Windows 개발 PC에는 없을 수 있다.
  사용법: `python3 render.py <데이터.json> <출력폴더>`
- `example-vol1.json` — Vol.1 실제 발행분 그대로. 새 회차를 만들 때 이 파일을 복사해서 값만 바꾸면 된다.

## 이번 회(Vol.N) 만드는 순서
1. `data/posts.json`에서 기존 `chukjemoa-weekly-vol*` slug 중 가장 큰 N을 찾아 N+1을 이번 회차 번호로 쓴다.
2. 아래 「데이터 코너 로테이션」에 따라 이번 주 데이터 페이지를 정하고, **그 페이지의 실제 빌드 결과(HTML)나
   원본 데이터 파일을 직접 읽어서** 1위(또는 핵심) 항목·숫자를 뽑는다. 절대로 숫자를 추측해서 쓰지 않는다.
3. `example-vol1.json`을 복사해 `vol{N}.json`을 만들고 이번 회 텍스트로 채운다. 원칙:
   - **원문 절대 복사 금지** — 외부 뉴스·타 사이트 내용을 인용하려면 장남 님이 이 세션에 직접 텍스트로
     전달한 것만 쓴다. 스스로 웹을 검색해서 뉴스를 요약해 넣지 않는다(저작권·정확성 문제).
   - 아이템 1: 계절/여행 트렌드에 대한 일반적인 관찰(사이트 자체 톤으로, 외부 출처 인용 없이)
   - 아이템 2: 이번 회 데이터 하이라이트 페이지 소개(실제 숫자 포함, 내부링크)
   - 아이템 3: 사이트의 다른 기능/허브 하나를 소개(예: `/course/`·`/trip/`·`/jangteo/`) — 매주 다른 것을
     골라 내부링크 다양성을 만든다. Vol.1처럼 매번 "시리즈 소개"를 반복할 필요는 없다.
   - 상품(구매 유도)은 넣지 않는다 — `blogAutoKeys()`/`festival` 안전망이 자동으로 처리한다.
4. `render.py vol{N}.json cardnews/out/vol{N}/` 실행 → `card1.png`~`card6.png` 생성 확인(6장, 파일 크기
   >0). 렌더된 PNG를 실제로 열어 보고(Read 도구) 텍스트가 카드 밖으로 넘치지 않았는지 확인한다.

## 데이터 코너 로테이션
Vol.1은 `/healing/`을 특집으로 다뤘다. 다음 회부터는 아래 순서로 **실제로 "1위/핵심 항목"이 명확한
페이지만** 로테이션한다 — 순위가 없는 페이지(단순 목록)는 "1위"를 지어내게 되므로 로테이션에 넣지 않는다.

```
(N-2) % 2 == 0  →  /hot/      (성수기 배수가 가장 «높은» 동네 — 핫플레이스)
(N-2) % 2 == 1  →  /healing/  (성수기 배수가 가장 «낮은» 동네 — 웰니스/한적함)
```

즉 Vol.2는 `/hot/`, Vol.3은 `/healing/`, Vol.4는 `/hot/`… 순으로 번갈아 쓴다. `/healing/`은 매달
데이터가 갱신되므로 Vol.1과 같은 지역이 나오더라도 배수 수치가 바뀌어 있을 수 있다 — 반드시 그 시점의
실제 빌드 결과에서 다시 뽑을 것.

다른 랭킹형 페이지(`/trend/`의 지역 랭킹 등)를 새로 로테이션에 추가하고 싶으면, 그 페이지가 진짜
"1위가 명확한 순위 데이터"를 갖고 있는지 먼저 확인한 뒤 이 문서에 추가한다.

## 검증 체크리스트 (발행 전 필수)
- [ ] `vol{N}.json`의 `{{TOKEN}}`이 전부 채워졌는가 (`render.py`가 안 채워진 토큰이 있으면 에러로 알려줌)
- [ ] 데이터 코너 숫자가 실제 빌드 결과에서 나온 값과 일치하는가
- [ ] 카드 6장 PNG가 전부 생성됐고, 텍스트가 카드 밖으로 넘치지 않는가(육안 확인)
- [ ] 사이트 글(`data/posts.json`) 쪽 본문에도 같은 데이터 코너 숫자를 인용해 일관성을 맞췄는가
