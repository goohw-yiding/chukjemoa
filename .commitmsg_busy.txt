열차 소요시간·운임 79개 역 확보 - API 셋보다 코레일 공식 XLSX 가 정확했다

/ja/daytrip/ 에 쓸 소요시간이 없어서 세 군데를 두드렸다.

1. 네이버 지도 API — NCP Directions 5 공식 문서 「자동차에 한해서만 제공」. 애초에 불가
2. ODsay — 호출은 되는데 «틀린다». 대전 251분·신탄진 266분(버스 경로) ·
   천안 118분·수원 60분(수도권 전철 경로) · 조치원 35분(무엇을 탔는지도 안 나옴).
   처음 세 개(부산 138·전주 86·강릉 92)가 맞아서 「된다」고 믿을 뻔했다
3. TAGO 열차정보 — 맞는 길이지만 활용신청이 필요

그런데 코레일이 「KTX 시간표」·「KTX 운임표」를 공식 XLSX 로 그냥 배포하고 있었다.
신청도 키도 필요 없고, 소요시간과 운임을 한꺼번에 준다.

- parse-train-timetable.py: 두 파일 → data/train_time.json
  79개 역 · 78개에 소요시간+운임 둘 다 · 출발역별로 따로(서울·용산·청량리·수서·행신·판교)
  대전 47분 / 강릉 87분 / 전주 88분 / 동대구 91분 / 부산 131분 — 실제 시각표와 일치
  2시간 이내 49개 역이 「日帰り」 후보가 된다

읽을 때 걸린 것 두 가지를 주석에 남겼다.
· 00:00 은 시각이 아니라 «그 역에 서지 않는다»는 뜻이다
· 한 헤더 행에 하행·상행이 좌우로 나란히 있다. 「비고」가 하행의 끝이다

원본은 data/raw/ 에 남긴다(어느 시점 시간표인지 나중에 확인해야 한다).
data/ 는 .vercelignore 라 배포에는 안 올라간다.
