1) 서치콘솔 '이벤트: description 입력란이 누락되었습니다' 15건 해소
   - /holiday/ Event JSON-LD에 description·eventAttendanceMode 추가
   - 공공데이터에 개요(ov)가 없는 축제가 많아, 없으면 일정·장소로 한 문장을 만드는
     evDesc() 폴백을 두었다. /search/ 쪽 eventsJsonLd도 같은 함수로 통일
   - image·addressLocality·streetAddress도 함께 채움. 검증: Event 15건 전부 통과

   - ogImageFor()가 URL 성격에 맞는 대표 이미지를 자동 선택(계곡·단풍·봄꽃·온천·
     오일장·걷기길·연휴·겨울/여름 월별), 기본값 hero.webp
   - og:site_name·og:locale·og:image:width/height·twitter:card(summary_large_image) 동반
   - /about/·/contact/는 build.js가 아닌 정적 파일이라 직접 삽입
   → 카톡·SNS·숏폼에 링크 붙일 때 썸네일이 뜬다(그동안 전부 안 떴음)

   - 해시 전에 날짜·D-day 배지처럼 매일 바뀌는 부분은 제거
